# phishing-incident-analysis
A defensive analysis of a suspected e-commerce phishing/social-engineering email, including email metadata, URL behavior, HTTP analysis, and investigation methodology.

## Overview

This repository documents the defensive investigation of a suspicious e-commerce
email that initially appeared consistent with a phishing/social-engineering attempt.

The investigation examines:

- Email metadata
- Sender authentication
- Social-engineering indicators
- URL structure
- HTTP redirects
- Destination infrastructure
- Threat-intelligence results
- Investigation limitations
