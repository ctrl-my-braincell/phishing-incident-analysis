# Evidence

This directory contains supporting evidence collected during the phishing investigation.

## Evidence Handling

Screenshots and other artifacts should be reviewed for sensitive information before being added to the repository.

The following information should be redacted where applicable:

* Personal email addresses
* Message IDs
* Tracking identifiers
* Authentication tokens
* Session identifiers
* Private IP addresses
* Other information that could identify the recipient or expose sensitive data

## Planned Evidence

The investigation may include:

* Redacted email metadata
* `Authentication-Results` header
* URL analysis output
* HTTP redirect results
* DNS or infrastructure observations
* Threat-intelligence results
* Relevant screenshots

Evidence should be accompanied by enough context to explain what was observed, when it was collected, and how it relates to the investigation.

## Integrity

Original evidence should be preserved separately from the sanitized material published in this repository.

Sensitive or personally identifying information should not be committed to the public repository.
